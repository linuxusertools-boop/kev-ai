Dokumentasi

Tanpa API key. Setiap chat punya ID chat (session-id) seperti KEVAI7QX2M9T dengan memori dan prompt default sendiri. Ambil ID di /home setelah login Google. Anggap ID sebagai kunci: siapa pun yang memegangnya bisa memakai chat itu.

Halaman

PathFungsi
/homeLogin Google, ambil ID chat, coba AI, latih AI
/chat/IDHalaman chat untuk satu ID (tanpa login)
/docsHalaman ini

Mengirim ID

Pilih salah satu: header x-session-id: ID (disarankan), Authorization: Bearer ID, path /api/ID, atau parameter session=ID. ID di URL ikut tercatat di log server dan riwayat browser.

Endpoint

EndpointMethodFungsi
/api atau /api/IDGET, POSTKirim pesan. Parameter text (atau prompt), maks 4000 karakter. Balasan dan pesan masuk ke memori.
/api/configGET, PUTBaca / ubah systemPrompt (prompt default, maks 4000) dan knowledge (array, maks 20 item @ 500 karakter). Selalu dikirim utuh di setiap pesan.
/api/historyGET, DELETELihat (limit 1-100) atau hapus memori percakapan.

Memori

  
Server menyimpan 200 pesan terakhir per chat dan mengirim sampai 30 pesan terbaru (maks 12.000 karakter) di setiap permintaan. Prompt default dan pengetahuan latihan tidak pernah dipotong.
